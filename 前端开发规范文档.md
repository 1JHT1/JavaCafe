## 4. API 接口契约

### 4.1 基础信息

- **Base URL**: `http://localhost:8080`
- **Content-Type**: `application/json`
- **通用响应格式**:

```typescript
interface ApiResponse<T> {
  code: number;    // 200 = 成功
  message: string;
  data: T;
}
```

### 4.2 接口列表

#### 4.2.1 开始面试 (4 种模式)

```
POST /api/interview/{mode}
```

| mode       | 咖啡名     | 说明               |
| ---------- | ---------- | ------------------ |
| `pour-over` | 手冲       | 项目深挖           |
| `americano` | 美式       | 系统设计           |
| `latte`     | 拿铁       | 八股文问答         |
| `special`   | 当季特调   | 综合模拟随机       |

**Request Body**:

```typescript
interface StartInterviewRequest {
  mode: "POUR_OVER" | "AMERICANO" | "LATTE" | "SPECIAL";
  resumeId?: string;    // 手冲模式可选，简历文件 ID
  maxRounds?: number;   // 最大轮数，默认 10
}
```

**Response**: `ApiResponse<string>` — `data` 为 `sessionId`

#### 4.2.2 获取 SSE 流

```
GET /api/interview/stream/{sessionId}
```

- 返回 `text/event-stream`，保持连接直到会话结束
- 详见第 5 节 SSE 协议

#### 4.2.3 提交回答

```
POST /api/interview/answer
```

**Request Body**:

```typescript
interface UserAnswerRequest {
  sessionId: string;
  answer: string;
}
```

**Response**: `ApiResponse<string>` — `data` 为 `"ok"`

#### 4.2.4 结束面试 (生成报告)

```
POST /api/interview/{sessionId}/end
```

**Response**: `ApiResponse<string>` — `data` 为 `"ok"`，报告通过 SSE 推送

### 4.3 前端 API 封装

```typescript
// src/api/client.ts
const BASE_URL = import.meta.env.VITE_API_BASE || 'http://localhost:8080';

export async function apiPost<T>(path: string, body?: unknown): Promise<ApiResponse<T>> {
  const res = await fetch(`${BASE_URL}${path}`, {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: body ? JSON.stringify(body) : undefined,
  });
  if (!res.ok) {
    const err = await res.json().catch(() => ({}));
    throw new ApiError(res.status, err.message || 'Request failed');
  }
  return res.json();
}

// src/api/interview.ts
export const interviewApi = {
  start: (mode: string, body: StartInterviewRequest) =>
    apiPost<string>(`/api/interview/${mode}`, body),

  answer: (body: UserAnswerRequest) =>
    apiPost<string>('/api/interview/answer', body),

  end: (sessionId: string) =>
    apiPost<string>(`/api/interview/${sessionId}/end`),
};
```

## 5. SSE 流式事件协议

### 5.1 连接方式

```typescript
const eventSource = new EventSource(`${BASE_URL}/api/interview/stream/${sessionId}`);
```

前端**不直接使用 `EventSource`**，而是封装在 `useSSE` Hook 中（见 7.4 节）。

### 5.2 事件类型

| 事件名     | data 格式   | 触发时机                         | 前端行为                       |
| ---------- | ----------- | -------------------------------- | ------------------------------ |
| `question` | 纯文本      | AI 提出新问题                    | 新增面试官气泡，显示问题       |
| `message`  | 纯文本      | AI 的中间回复/评价               | 新增或更新面试官气泡           |
| `report`   | JSON 字符串 | 面试结束，生成杯测报告           | 解析 JSON，跳转报告页          |
| `complete` | `{}`        | 当前阶段对话结束 (等待用户输入)  | 解锁输入框，隐藏加载动画       |
| `error`    | 纯文本      | 发生错误                         | 显示 error toast               |

### 5.3 SSE 数据流时序

```
客户端                      服务端
  │                          │
  ├─ POST /latte ───────────>│  开始拿铁面试
  │<─────── sessionId ───────┤
  │                          │
  ├─ GET /stream/{id} ──────>│  建立 SSE 连接
  │<── event:question ───────┤  AI 提出第1个问题
  │      data: "请解释..."    │
  │<── event:complete ───────┤  等待用户回答
  │                          │
  ├─ POST /answer ──────────>│  用户提交回答
  │<── event:message ────────┤  AI 评价 + 第2个问题
  │      data: "很好..."      │
  │<── event:complete ───────┤
  │                          │
  │        ... (循环) ...     │
  │                          │
  ├─ POST /{id}/end ────────>│  结束面试
  │<── event:report ─────────┤  杯测报告 JSON
  │<── event:complete ───────┤  会话结束
  │                          │
```

### 7.4 useSSE Hook

```typescript
// src/hooks/useSSE.ts
import { useEffect, useRef, useCallback } from 'react';

interface UseSSEOptions {
  sessionId: string | null;
  onEvent: (type: SseEventType, data: string) => void;
  onError?: (error: string) => void;
}

export function useSSE({ sessionId, onEvent, onError }: UseSSEOptions) {
  const eventSourceRef = useRef<EventSource | null>(null);

  const connect = useCallback(() => {
    if (!sessionId) return;

    const es = new EventSource(
      `${import.meta.env.VITE_API_BASE}/api/interview/stream/${sessionId}`
    );

    es.addEventListener('question', (e) => onEvent('question', e.data));
    es.addEventListener('message', (e) => onEvent('message', e.data));
    es.addEventListener('report', (e) => onEvent('report', e.data));
    es.addEventListener('complete', () => onEvent('complete', '{}'));
    es.addEventListener('error', (e) => {
      onError?.('SSE connection error');
    });

    eventSourceRef.current = es;
  }, [sessionId, onEvent, onError]);

  const disconnect = useCallback(() => {
    eventSourceRef.current?.close();
    eventSourceRef.current = null;
  }, []);

  useEffect(() => {
    return () => disconnect();
  }, [disconnect]);

  return { connect, disconnect };
}
```

```
│  └──────────────────────────────┘        │
└──────────────────────────────────────────┘
```

**交互流程**:

1. 进入页面 → `POST /api/interview/{mode}` 创建 session → 拿到 sessionId
2. 建立 SSE 连接 → 接收 `question` 事件 → 显示问题气泡
3. 收到 `complete` 事件 → 解锁输入框
4. 用户输入回答 → `POST /api/interview/answer`
5. 收到 `message` 事件 → 显示 AI 评价/追问气泡
6. 循环 3-5 直到 maxRounds
7. 用户点击"结束面试"或达到 maxRounds → `POST /{id}/end`
8. 收到 `report` 事件 → 跳转 `/report/{sessionId}`

**Loading 状态**:

- SSE 连接中: 显示全屏咖啡豆加载动画
- AI 思考中 (收到 question 后到收到 complete 之间): 输入框禁用 + TypingIndicator 显示

**Empty 状态**: 无 — 进入页面即发起请求

**Error 状态**:

- SSE 连接失败: Toast "连接失败，请重试" + 返回首页按钮
- 提交回答失败: Toast "发送失败，请重试"
- 会话不存在: Toast "会话已过期"

**Edge Cases**:

- 用户直接关闭页面 → SSE 自动断开，后端 Redis TTL 2小时后清理
- 网络断开重连 → SSE 重连，从上次 `complete` 事件后的状态恢复
- 用户快速连续点击发送 → 输入框在 `complete` 前禁用，防止重复提交

**关键代码结构**:

```tsx
export default function InterviewPage() {
  const { mode } = useParams<{ mode: string }>();
  const navigate = useNavigate();
  const store = useInterviewStore();
  const [inputValue, setInputValue] = useState('');

  // 初始化面试
  useEffect(() => {
    interviewApi.start(mode!, { mode: modeToEnum(mode!), maxRounds: 10 })
      .then(res => {
        store.initSession(res.data, modeToEnum(mode!), 10);
      });
  }, [mode]);

  // SSE 事件处理
  const handleSseEvent = useCallback((type: SseEventType, data: string) => {
    switch (type) {
      case 'question':
        store.addMessage('interviewer', data);
        store.setStreaming(true);
        break;
      case 'message':
        store.addMessage('interviewer', data);
        break;
      case 'complete':
        store.setStreaming(false);
        break;
      case 'report':
        const report = JSON.parse(data);
        store.endSession(report);
        navigate(`/report/${store.sessionId}`);
        break;
      case 'error':
        toast.error(data);
        break;
    }
  }, []);

  const { connect } = useSSE({
    sessionId: store.sessionId,
    onEvent: handleSseEvent,
  });

  useEffect(() => {
    if (store.sessionId) connect();
  }, [store.sessionId]);

  const handleSend = () => {
    if (!inputValue.trim() || store.isStreaming) return;
    store.addMessage('user', inputValue);
    interviewApi.answer({ sessionId: store.sessionId!, answer: inputValue });
    setInputValue('');
  };

  return (
    <div className="h-screen flex flex-col bg-cream">
      <InterviewToolbar mode={mode} round={store.currentRound} maxRounds={store.maxRounds} />
      <div className="flex-1 overflow-y-auto p-4 space-y-4">
        {store.messages.map(msg => (
          <ChatBubble key={msg.id} role={msg.role} content={msg.content} />
        ))}
        {store.isStreaming && <TypingIndicator />}
      </div>
      <ChatInput
        value={inputValue}
        onChange={setInputValue}
        onSend={handleSend}
        disabled={store.isStreaming}
      />
    </div>
  );
}
```
